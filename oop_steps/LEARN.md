# C语言OOP 5步通关

> 只有5个文件，每个文件只讲1个概念。
> 按顺序打开→编译→运行→动手改，做完即精通。

---

## 学习路线

```
00_data.c      结构体打包数据    ← 对象 = 数据的容器    5分钟
01_funcptr.c   函数指针做方法    ← 对象 = 数据 + 行为    5分钟
02_encaps.c    封装内部实现      ← 隐藏细节，只露接口   5分钟
03_inherit.c   继承复用代码      ← 基类嵌入派生类        5分钟
04_polymorph.c 多态统一接口      ← 虚表实现运行时派发    10分钟
                                    ──────────────
                                    总共约30分钟
```

## 怎么学

每个文件都遵循同样的结构：

```
1. 文件开头的注释 → 告诉你这步要学什么
2. 可编译运行的代码 → 边读边跑
3. 文件末尾的"理解检查" → 确认你懂了
4. "动手改改看" → 改完才算真会
```

## 运行方法

```sh
# 如果你有 gcc（Linux/WSL/macOS/MinGW）
cd oop_steps
gcc 00_data.c && ./a.out   # 改一次编译一次

# 如果没有 gcc：在 https://godbolt.org/ 粘贴代码在线跑
```

## 阅读顺序

第0步 → 第1步 → 第2步 → 第3步 → 第4步

**不要跳步。** 每一步都建立在上一步之上。
做完一步后，一定要做"动手改改看"的练习。
